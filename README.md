
# SEVER FINANCE Landing Page

Это лендинг для компании SEVER FINANCE — современный, адаптивный, выполнен в фирменных цветах и на TailwindCSS.

## 📁 Содержимое

- `index.html` — главный HTML-файл с подключением TailwindCSS и ссылкой на JS-скрипт
- `sever-finance-landing.js` — скрипт, подключающий React-компонент
- (дополнительно нужно добавить `LandingPage.jsx` — сам React-компонент)

## 🚀 Размещение на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `sever-finance-site`).
2. Загрузите в него файлы:
   - `index.html`
   - `sever-finance-landing.js`
   - `LandingPage.jsx` (из вашего проекта React)
3. Убедитесь, что все файлы находятся в корне репозитория.
4. Перейдите в **Settings > Pages**.
5. В разделе **Source** выберите ветку `main` и папку `/root` (или `/docs`, если вы туда загрузили файлы).
6. Нажмите **Save** — ваш сайт станет доступен по адресу вида:  
   `https://your-username.github.io/sever-finance-site/`

## 📌 Дополнительно

- Вы можете использовать Vite, React Scripts или любой сборщик, если хотите более интерактивную версию.
- TailwindCSS подключается через CDN, так что вам не нужен сборщик стилей.
